# 🌱 ทบทวน if / else และ Loop ในภาษา C

เริ่มทีละเรื่อง ลองทายผลก่อนรัน แล้วเปลี่ยนค่าตัวเลขเพื่อดูว่าโปรแกรมทำงานต่างไปอย่างไร ไม่ต้องจำทุกอย่างในครั้งเดียว

**เป้าหมาย:** เลือกทำงานตามเงื่อนไขได้ และเขียนลูปสั้น ๆ ที่หยุดได้ถูกต้อง เพื่อเตรียมต่อยอดเรื่อง Array

## แผนทบทวนประมาณ 45–60 นาที

| ช่วง | เนื้อหา | ลงมือทำ |
| --- | --- | --- |
| 10 นาที | เงื่อนไขและ `if / else` | แลป 1–2 |
| 10 นาที | `for` และการนับรอบ | แลป 3 |
| 10 นาที | `while` และการเปลี่ยนค่าตัวแปร | แลป 4 |
| 10 นาที | `do...while` | แลป 5 |
| 5–20 นาที | การสะสมผลรวมและทบทวน | แลป 6 ตามเวลาที่เหลือ |

ถ้าเวลาน้อย ให้ทำข้อ 1 และ 3 ให้เข้าใจก่อน ไม่จำเป็นต้องทำครบทุกข้อในครั้งเดียว

## 1. เงื่อนไขคือคำถามที่ตอบได้ว่าจริงหรือเท็จ

| เครื่องหมาย | ความหมาย | ตัวอย่างที่เป็นจริง |
| --- | --- | --- |
| `==` | เท่ากับ | `5 == 5` |
| `!=` | ไม่เท่ากับ | `5 != 3` |
| `>` / `<` | มากกว่า / น้อยกว่า | `5 > 3` |
| `>=` / `<=` | มากกว่าหรือเท่ากับ / น้อยกว่าหรือเท่ากับ | `5 >= 5` |
| `&&` | และ: ต้องจริงทั้งคู่ | `score >= 0 && score <= 100` เมื่อ `score` เป็น 70 |
| `||` | หรือ: จริงอย่างน้อยหนึ่งฝั่ง | `score < 0 || score > 100` เมื่อ `score` เป็น 120 |
| `!` | กลับค่าจริงเป็นเท็จ เท็จเป็นจริง | `!(5 < 3)` |

ในภาษา C ค่า `0` เป็นเท็จ ส่วนค่าที่ไม่ใช่ `0` เป็นจริง

**ระวัง:** `=` ใช้กำหนดค่า แต่ `==` ใช้เปรียบเทียบ และการตรวจช่วงต้องเขียน `score >= 0 && score <= 100` ไม่เขียน `0 <= score <= 100`

## 2. if / else: เลือกทางเดิน

ตัวอย่างต่อไปนี้เป็นโปรแกรมเต็ม สามารถคัดลอกไปลองได้ ส่วนตัวอย่างหัวข้ออื่นเป็นโค้ดที่ใส่ภายใน `main`

```c
#include <stdio.h>

int main(void)
{
    int score = 60;
    if (score >= 50) {
        printf("PASS\n");
    } else {
        printf("TRY AGAIN\n");
    }
    return 0;
}
```

เมื่อคะแนนเป็น 60 โปรแกรมพิมพ์ `PASS` เพียงบรรทัดเดียว ลองเปลี่ยนเป็น 49 และ 50 แล้วทายผลก่อนรัน

- `if` ทำงานเมื่อเงื่อนไขเป็นจริง
- `else` ทำงานเมื่อเงื่อนไขของ `if` เป็นเท็จ และไม่ต้องใส่เงื่อนไขต่อท้าย `else`
- ถ้ามีงานที่ทำเฉพาะเมื่อเงื่อนไขจริง สามารถใช้ `if` โดยไม่มี `else` ได้
- ใช้ `{ }` ครอบแต่ละส่วนไว้เสมอในแบบฝึกหัดนี้ เพื่อให้อ่านขอบเขตได้ชัด

### ถ้ามีมากกว่า 2 ทาง: else if

```c
int score = 65;
if (score >= 80) {
    printf("A\n");
} else if (score >= 50) {
    printf("PASS\n");
} else {
    printf("TRY AGAIN\n");
}
```

ตรวจจากบนลงล่างและทำเฉพาะทางแรกที่เงื่อนไขจริง จึงพิมพ์ `PASS` ควรวางเกณฑ์ 80 ก่อน 50 เพราะคะแนน 85 ผ่านทั้งสองเงื่อนไข

`if` หลายอันที่แยกจากกันจะตรวจทุกอัน แต่ชุด `if / else if / else` เลือกทำเพียงทางเดียว

## 3. for: ทำซ้ำแบบนับรอบ

```c
for (int i = 1; i <= 3; i++) {
    printf("%d\n", i);
}
```

ผลลัพธ์คือ 1, 2, 3 คนละบรรทัด

อ่านส่วนในวงเล็บว่า **เริ่มที่ไหน → ทำต่อเมื่ออะไร → หลังจบรอบเปลี่ยนค่าอย่างไร**

1. `int i = 1` ทำครั้งเดียวก่อนเริ่มลูป
2. ตรวจ `i <= 3` ถ้าจริงจึงเข้าทำงานใน `{ }`
3. เมื่อจบรอบ ทำ `i++` ซึ่งเพิ่มค่า `i` อีก 1 แล้วกลับไปตรวจเงื่อนไข
4. เมื่อเงื่อนไขเป็นเท็จ จบลูป

| i ตอนตรวจเงื่อนไข | i <= 3 | สิ่งที่พิมพ์ |
| --- | --- | --- |
| 1 | จริง | 1 |
| 2 | จริง | 2 |
| 3 | จริง | 3 |
| 4 | เท็จ | ไม่พิมพ์และจบลูป |

ลองเปลี่ยน `<= 3` เป็น `< 3` จะเหลือกี่รอบ? **2 รอบ** เพราะไม่รวมค่า 3

## 4. while: ตรวจเงื่อนไขก่อนทำ

```c
int count = 3;
while (count > 0) {
    printf("%d\n", count);
    count--;
}
```

พิมพ์ 3, 2, 1 คนละบรรทัด โดย `count--` ลดค่าทีละ 1 หากเริ่มที่ 0 จะไม่ทำงานในลูปเลย

จำให้ครบ 3 อย่าง: **ค่าเริ่มต้น เงื่อนไข และการเปลี่ยนค่า** ถ้าลืมลด `count` ในตัวอย่างนี้ เงื่อนไขจะจริงตลอดจนกลายเป็นลูปไม่จบ

## 5. do...while: ทำก่อน แล้วค่อยตรวจ

```c
int count = 0;
do {
    printf("HELLO\n");
    count++;
} while (count < 0);
```

แม้เงื่อนไขจะเป็นเท็จตอนตรวจ โปรแกรมก็พิมพ์ `HELLO` ไปแล้ว 1 ครั้ง เพราะตรวจหลังทำงาน

**ต้องมี `;` หลัง `while (...)` ของ do...while**

| ลูป | ตรวจเงื่อนไขเมื่อไร | จำนวนรอบน้อยที่สุด | ตัวอย่างการใช้ |
| --- | --- | --- | --- |
| `for` | ก่อนทำแต่ละรอบ | 0 | พิมพ์เลข 1–5 |
| `while` | ก่อนทำแต่ละรอบ | 0 | นับถอยหลังขณะที่ค่ายังมากกว่า 0 |
| `do...while` | หลังทำแต่ละรอบ | 1 | งานที่ต้องทำอย่างน้อยหนึ่งครั้ง |

ทั้งสามแบบใช้แทนกันได้ในหลายกรณี เลือกแบบที่อ่านแล้วเข้าใจง่ายที่สุด

## 6. สะสมผลรวมทีละรอบ

```c
int sum = 0;
for (int i = 1; i <= 3; i++) {
    sum = sum + i;
}
printf("%d\n", sum);
```

| รอบ | i | sum ก่อนบวก | sum หลังบวก |
| --- | --- | --- | --- |
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |

ตั้ง `sum = 0` **ก่อนลูป** เพื่อเก็บผลจากรอบก่อนหน้า และพิมพ์หลังลูปเมื่อต้องการแค่คำตอบสุดท้าย `sum += i` เป็นรูปย่อของ `sum = sum + i`

## 🔎 จุดที่มักพลาด

| อาการ | ลองตรวจอะไร |
| --- | --- |
| เงื่อนไขแปลก ๆ | ใช้ `=` แทน `==` หรือไม่ |
| ทำงานเกินหนึ่งรอบ | ต้องใช้ `<` หรือ `<=` และเริ่มนับจากค่าใด |
| โปรแกรมพิมพ์ไม่หยุด | ลืมเพิ่ม/ลดตัวแปรหรือไม่ กด Ctrl+C เพื่อหยุดได้ |
| คำสั่งทำงานนอกเงื่อนไขหรือลูป | มี `;` เกินหลัง `if (...)`, `for (...)` หรือ `while (...)` หรือไม่ |
| ผลรวมไม่สะสม | ตั้ง `sum = 0` ซ้ำในลูปหรือไม่ |
| คอมไพล์ do...while ไม่ผ่าน | มี `;` หลัง `while (...)` แล้วหรือยัง |
