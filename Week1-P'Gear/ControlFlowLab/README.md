# 🌱 แลปเริ่มต้น · If / Else & Loops

**6 ข้อเล็ก ๆ ทำทีละข้อได้เลย** ไม่ต้องเขียนทั้งโปรแกรมเอง: แต่ละไฟล์มี `main` ให้แล้ว เติมเฉพาะจุด `TODO` ก็พอ ข้อ 1–5 เป็นพื้นฐาน ส่วนข้อ 6 เป็นข้อเสริมเมื่อเริ่มคล่อง

ก่อนเริ่ม อ่าน [ชีตทบทวน](../Handouts/Control_Flow_Review_TH.md) ได้ ไม่ต้องใช้ Array หรือ `scanf` ในแลปชุดนี้

## วิธีทำ

1. เปิดไฟล์ของข้อที่ต้องการ แล้วเติมโค้ดตรง `TODO`
2. เปิด Terminal ในโฟลเดอร์ `ControlFlowLab`
3. คอมไพล์และรันทีละไฟล์ ตัวอย่างข้อ 1 บน Linux / macOS / WSL:

```bash
gcc -std=c99 -Wall -Wextra -pedantic 01_pass_fail.c -o practice
./practice
```

บน Windows PowerShell ที่มี GCC ใน PATH:

```powershell
gcc -std=c99 -Wall -Wextra -pedantic 01_pass_fail.c -o practice.exe
.\practice.exe
```

ข้อถัดไปให้เปลี่ยนชื่อไฟล์ `.c` ในคำสั่ง และ **คอมไพล์ใหม่ทุกครั้งหลังแก้โค้ด** แลปนี้ไม่มีตัวตรวจคะแนนอัตโนมัติ ให้เทียบผลลัพธ์กับตัวอย่างด้านล่าง ไฟล์ตั้งต้นบางข้ออาจมีคำเตือนว่าตัวแปรยังไม่ได้ใช้ ซึ่งจะหายไปเมื่อเติมโค้ดที่ใช้ตัวแปรนั้น

ถ้าติด ลองเปิดคำใบ้ก่อนเฉลย และเมื่อทำได้แล้วให้เปลี่ยนค่าทดลองอีกครั้งเพื่อเช็กความเข้าใจ

## 1. คะแนนผ่านหรือยัง? · if / else

📄 [01_pass_fail.c](01_pass_fail.c)

มี `score = 60` ให้แล้ว ถ้าคะแนนตั้งแต่ 50 ขึ้นไป พิมพ์ `PASS` ไม่เช่นนั้นพิมพ์ `TRY AGAIN` ให้พิมพ์เพียงหนึ่งบรรทัด สมมติคะแนนอยู่ในช่วง 0–100

| เปลี่ยน score เป็น | ผลลัพธ์ที่ควรได้ |
| --- | --- |
| 60 | `PASS` |
| 49 | `TRY AGAIN` |
| 50 | `PASS` |

<details>
<summary>💡 คำใบ้</summary>

ใช้ `if (score >= 50)` แล้วเขียน `else` สำหรับอีกกรณี คำสั่งพิมพ์คือ `printf("PASS\n");`

</details>

## 2. เลขคู่หรือเลขคี่? · if / else

📄 [02_even_odd.c](02_even_odd.c)

มี `number = 4` ให้แล้ว ถ้าเป็นเลขคู่พิมพ์ `EVEN` ถ้าเป็นเลขคี่พิมพ์ `ODD` ทดลองกับจำนวนเต็ม 0–100

**ความรู้เพิ่ม:** `%` คือการหาเศษจากการหาร เช่น `4 % 2` ได้ 0 ส่วน `5 % 2` ได้ 1 เลขที่หาร 2 ลงตัวคือเลขคู่

| เปลี่ยน number เป็น | ผลลัพธ์ที่ควรได้ |
| --- | --- |
| 4 | `EVEN` |
| 5 | `ODD` |
| 0 | `EVEN` |

<details>
<summary>💡 คำใบ้</summary>

โครงสร้างเหมือนข้อ 1 เปลี่ยนเงื่อนไขเป็น `number % 2 == 0` และเปลี่ยนข้อความที่พิมพ์

</details>

## 3. นับเลข 1 ถึง 5 · for

📄 [03_for_count.c](03_for_count.c)

ใช้ `for` พิมพ์เลข 1 ถึง 5 คนละบรรทัด โดยไม่เขียน `printf` ซ้ำ 5 ครั้ง

```text
1
2
3
4
5
```

<details>
<summary>💡 คำใบ้</summary>

เริ่มที่ `int i = 1` ทำต่อเมื่อ `i <= 5` และเพิ่มค่าด้วย `i++` ภายในลูปใช้ `printf("%d\n", i);`

</details>

✅ ทำได้แล้วลองเปลี่ยนให้พิมพ์ถึง 3 ผลต้องเหลือ 1, 2, 3 คนละบรรทัด

## 4. นับถอยหลัง 3 ถึง 1 · while

📄 [04_while_countdown.c](04_while_countdown.c)

มี `count = 3` ให้แล้ว ใช้ `while` พิมพ์ค่าจาก 3 ลดลงถึง 1 คนละบรรทัด

```text
3
2
1
```

<details>
<summary>💡 คำใบ้</summary>

ทำต่อเมื่อ `count > 0` ภายในลูปให้พิมพ์ก่อน แล้วใช้ `count--;` ลดค่าลง อย่าลืมบรรทัดนี้ ไม่เช่นนั้นโปรแกรมจะพิมพ์ไม่หยุด

</details>

✅ ลองเริ่ม `count = 1` ต้องพิมพ์ 1 ครั้ง และเมื่อเริ่ม `count = 0` ต้องไม่พิมพ์อะไร

## 5. ทักทาย 3 ครั้ง · do...while

📄 [05_do_while_hello.c](05_do_while_hello.c)

มี `count = 1` ให้แล้ว ใช้ `do...while` พิมพ์ข้อความต่อไปนี้ โดยเพิ่ม `count` หลังพิมพ์แต่ละรอบ และทำต่อเมื่อ `count <= 3`

```text
HELLO
HELLO
HELLO
```

<details>
<summary>💡 คำใบ้</summary>

วางคำสั่งพิมพ์และ `count++;` ใน `do { ... }` แล้วปิดด้วย `while (count <= 3);` อย่าลืม `;` ท้ายบรรทัด

</details>

✅ ลองเริ่ม `count = 4` จะยังพิมพ์ `HELLO` หนึ่งครั้ง เพราะตรวจเงื่อนไขหลังทำงาน

## 6. บวกเลข 1 ถึง n · ข้อเสริม

📄 [06_sum.c](06_sum.c)

มี `n = 5` และ `sum = 0` ให้แล้ว ใช้ `for` บวกเลข 1 ถึง n เก็บใน `sum` โดยใช้ n ในเงื่อนไขลูป โค้ดพิมพ์คำตอบเตรียมไว้แล้ว สมมติ n อยู่ในช่วง 1–100

| n | สิ่งที่คำนวณ | ผลลัพธ์ |
| --- | --- | --- |
| 5 | 1 + 2 + 3 + 4 + 5 | `15` |
| 3 | 1 + 2 + 3 | `6` |
| 1 | 1 | `1` |

<details>
<summary>💡 คำใบ้</summary>

ใช้ลูปคล้ายข้อ 3 แต่จบที่ n และเปลี่ยนจากการพิมพ์เป็น `sum = sum + i;` ไม่ต้องตั้ง `sum` เป็น 0 ซ้ำในลูป

</details>

## 🎉 เช็กสิ่งที่ทำได้

- [ ] ฉันเลือกข้อความที่จะพิมพ์ด้วย if / else ได้
- [ ] ฉันใช้ for นับขึ้นได้
- [ ] ฉันใช้ while นับถอยหลังและหยุดได้
- [ ] ฉันอธิบายได้ว่าทำไม do...while ทำอย่างน้อยหนึ่งครั้ง
- [ ] ฉันลองเปลี่ยนค่าและทายผลก่อนรันแล้ว

ทำได้หนึ่งข้อก็คือเข้าใจเพิ่มหนึ่งเรื่อง ถ้าผลไม่ตรง ให้ไล่ค่าตัวแปรทีละรอบบนกระดาษแล้วลองใหม่

## เฉลยสำหรับเช็กหลังลองทำ

โค้ดด้านล่างใช้แทนคอมเมนต์ `TODO` ในแต่ละไฟล์ โดยเก็บส่วนอื่นของไฟล์ไว้เหมือนเดิม

<details>
<summary>เฉลยข้อ 1 · เลือกตามคะแนน</summary>

```c
if (score >= 50) {
    printf("PASS\n");
} else {
    printf("TRY AGAIN\n");
}
```

ใช้ `>=` เพื่อรวมคะแนน 50 ด้วย

</details>

<details>
<summary>เฉลยข้อ 2 · ตรวจเศษจากการหาร</summary>

```c
if (number % 2 == 0) {
    printf("EVEN\n");
} else {
    printf("ODD\n");
}
```

ใช้ `==` เพื่อเปรียบเทียบเศษกับ 0

</details>

<details>
<summary>เฉลยข้อ 3 · นับขึ้น</summary>

```c
for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
```

ทำ 5 รอบ และหยุดเมื่อ i เป็น 6

</details>

<details>
<summary>เฉลยข้อ 4 · นับลง</summary>

```c
while (count > 0) {
    printf("%d\n", count);
    count--;
}
```

เมื่อ count เป็น 0 เงื่อนไขเป็นเท็จ จึงหยุดก่อนพิมพ์ 0

</details>

<details>
<summary>เฉลยข้อ 5 · ทำก่อนตรวจ</summary>

```c
do {
    printf("HELLO\n");
    count++;
} while (count <= 3);
```

ค่า count ก่อนพิมพ์เป็น 1, 2, 3 ตามลำดับ หลังพิมพ์รอบที่ 3 เพิ่มเป็น 4 แล้วจบลูป

</details>

<details>
<summary>เฉลยข้อ 6 · สะสมผลรวม</summary>

```c
for (int i = 1; i <= n; i++) {
    sum = sum + i;
}
```

เมื่อ n เป็น 5 ค่า sum หลังแต่ละรอบคือ 1, 3, 6, 10, 15 โดยพิมพ์คำตอบครั้งเดียวหลังจบลูป

</details>

## สำหรับพี่ TA

เริ่มด้วยการทำตัวอย่างหนึ่งข้อร่วมกัน แล้วให้เด็กลองข้อที่โครงสร้างใกล้เคียงกัน ใช้คำถาม “ตอนนี้ตัวแปรมีค่าเท่าไร?” และ “รอบนี้เงื่อนไขจริงไหม?” ช่วยพาไล่โค้ด หากยังติด ให้เปิดเฉพาะคำใบ้ก่อน เมื่อทำได้ให้เด็กอธิบายหนึ่งประโยคว่าโค้ดหยุดหรือเลือกทางเพราะอะไร โดยยังไม่จำเป็นต้องจับเวลาให้คะแนน
